# Relatório — Capítulo 0.7 (novo): Dependências e contexto

## Inventário

| Seção | Cobre | Código |
| --- | --- | --- |
| A necessidade: a mesma ferramenta, lojas diferentes | `Agent(deps_type=)`, `deps_type`, `deps=`, `RunContext`, `RunContext[...]`, `.deps`; armadilha `deps` esquecido (`None`) | `dependencias_deps.py` |
| Tipos que o editor confere: `Agent[...]` | `Agent[Deps, Saída]`, verificação estática vs. execução | `dependencias_tipos.py` |
| Instruções que dependem da execução | `@instructions`, `.instructions` (`Agent.instructions` e `AgentInfo.instructions`), string vazia, reavaliação a cada requisição | `instrucoes_dinamicas.py` |
| O que mais o contexto sabe: `.retry` | `ctx.retry`, `ctx.max_retries`, `ctx.run_step`, `deps` é o mesmo objeto (mutação) | `contexto_retry.py` |
| Por que injetar, e como isso facilita o teste | injeção vs. variável global, `override(deps=)` | `dependencias_teste.py` |
