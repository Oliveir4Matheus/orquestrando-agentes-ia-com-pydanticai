# Relatório — Capítulo 0.4 (novo): O primeiro agente por dentro

## Inventário

| Seção | Símbolos cobertos | Código |
| --- | --- | --- |
| `Agent`: o objeto que conversa com o modelo | `Agent`, `Agent(instructions=)`, `Agent(name=)`, `.run_sync`, `.output`, `.usage`, `.requests`, `.input_tokens`, `.output_tokens`, `.total_tokens` | `agente_minimo.py` |
| A string `"provedor:modelo"` | string de modelo, `"test"`, `UserError`, `config.py` | `agente_modelo_string.py` |
| `instructions` ou `system_prompt`? | `system_prompt`, `SystemPromptPart`, `message_history` (só citado) | `agente_instrucoes.py` |
| Três formas de executar | `.run`, `.run_stream`, `.stream_text` (`delta`, `debounce_by`), `.get_output` | `agente_async.py` |
| Streaming de saída estruturada | `.stream_output` | `agente_stream_saida.py` |
| `ModelSettings` | `ModelSettings`, mescla agente/execução | `agente_configuracoes.py` |

Exercícios 0.4.1 a 0.4.12; ~3.000 palavras (incluindo código).

## Lacunas encontradas

| Lacuna | Tratamento |
| --- | --- |
| Os módulos usam `Agent(MODELO, instructions=...)` e `.run_sync(...).output` sem explicar o objeto de resultado | seções 1 e 2 |
| `config.py` (troca de modelo em uma linha) não era explicado | seção da string `"provedor:modelo"` |
| Diferença `instructions` x `system_prompt` | demonstrada com `FunctionModel` espião e histórico |
| Streaming (`run_stream`, `debounce_by`) | exemplo offline com `FunctionModel(stream_function=...)` |
