# Relatório — Capítulo 0.5 (novo): Mensagens e testes sem API

## Inventário

| Seção | Símbolos cobertos | Código |
| --- | --- | --- |
| O que trafega | `ModelMessage`, `ModelRequest`, `ModelResponse`, `.parts`, `.part_kind`, `kind` | `mensagens_conversa.py` |
| As partes por dentro | `UserPromptPart`, `ToolCallPart`, `ToolReturnPart`, `TextPart`, `RetryPromptPart` (tabela), `.content`, `.tool_name`, `.args`, `.args_as_dict`, `.tool_call_id` | `mensagens_partes.py` |
| Memória de conversa | `message_history`, `.all_messages`, `.new_messages` | `mensagens_historico.py` |
| Gravar e recuperar | `ModelMessagesTypeAdapter` (`dump_json`, `validate_json`) | `mensagens_salvar.py` |
| Testes sem API | `TestModel` (`call_tools`, `custom_output_text`, `custom_output_args`), `FunctionModel`, `AgentInfo`, `.function_tools`, `ModelResponse(parts=)`, `RetryPromptPart` via `ModelRetry` | `teste_functionmodel.py` |
| Inspecionar uma execução | `capture_run_messages` | `teste_functionmodel.py` |
| Agente de produção | `.override`, `ALLOW_MODEL_REQUESTS` | `teste_override.py` |

Exercícios 0.5.1 a 0.5.12 em 4 blocos; ~3.050 palavras (incluindo código e saídas).

## Lacunas encontradas

| Lacuna | Tratamento |
| --- | --- |
| O 0.4 usava `FunctionModel`/`TestModel` sem explicá-los e prometia o 0.5 | seção de testes |
| `args` pode ser dict ou texto JSON | demonstrado com `repr(.args)` x `.args_as_dict()` |
| Confusão `all_messages` x `new_messages` em vários turnos | armadilha + exercício 0.5.4 |
| Histórico vindo do cliente é não confiável | parágrafo de cuidado |

## O que foi adicionado

| Tipo | Item |
| --- | --- |
| Capítulo novo | `modulo-00/0.5-mensagens-e-testes-sem-api.md` |
| Código | `mensagens_conversa.py`, `mensagens_partes.py`, `mensagens_historico.py`, `mensagens_salvar.py`, `teste_functionmodel.py`, `teste_override.py` (offline, saída real) |
| Armadilhas | continuar com `new_messages()`; `FunctionModel` sem texto final (`UsageLimitExceeded` após 50 requisições); agente criado dentro da função escapa do `override` |
| Exercícios | 0.5.1 a 0.5.12 |

## Correções factuais sugeridas (não aplicadas)

Nenhuma. Observações conferidas no pydantic-ai 2.54.0: `teste_override.py` define uma chave falsa porque criar `Agent("anthropic:...")` exige `ANTHROPIC_API_KEY`; nenhuma requisição é feita (bloqueada por `ALLOW_MODEL_REQUESTS = False`). `override(model=)` prevalece até sobre `run_sync(model=...)`.
